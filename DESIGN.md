# BarbaroTech Signal Interface

## Direction

The site is a restrained futuristic sales portfolio. Dark mode is the first-visit default: deep navy creates focus, large white type states the offer, and icy blue carries light and system status. Visitors can switch to an ice-blue light mode with navy text. Cobalt owns primary conversion actions in both modes. The interface should feel engineered without becoming dense or decorative.

## Homepage flow

The hero rotates through five sales messages: free custom demo, pricing, static websites, the select-client care offer, and the CMS add-on. One moving light travels across the timeline and advances the message when it reaches the end. Desktop visitors receive arrows and topic controls. Touch users can swipe. The hero reserves a fixed content footprint so the previews and page below never jump as copy changes.

Clickable screenshots of every hosted portfolio site sit directly below the hero, replacing the logo belt and its navigation row. They form five columns on desktop, two on tablets, and a native swipe row on phones. The previews are static, with a single link to the complete live collection. The repeated website-type cards and duplicate featured-work gallery are removed; the previews lead straight into the concise capabilities section.

The complete live portfolio has category filters, text search, result counts, and a recoverable empty state. Live project cards show actual website captures where available, the real hosted destination, and a separate build-detail link. Only verified hosted projects enter this collection; local source alone is not evidence of publication.

Shopify services have a dedicated page linked from the navigation, homepage, services index, and footer. Cobalt sections distinguish Shopify services and planned theme releases without presenting unreleased themes as available products. The journal carries the same identity into a quieter reading surface with restrained metadata, real project images, a table of contents, and related articles.

## Surfaces

Dark panels use blue-black fills with thin icy-blue borders. Light mode remaps the canvas and panels to layered ice blues with navy text, rather than placing dark panels inside a pale page. Client-logo surfaces preserve the contrast required by each original mark. Primary calls to action remain cobalt in both modes.

## Typography

Archivo handles display and body copy. Headlines use tight tracking and short, balanced statements. Fragment Mono is limited to quiet system labels. Do not use visible list numbering as decoration. Real prices, dates, and evidence remain numeric when needed.

## Motion

Motion communicates state:

- The hero light indicates time remaining before the next message.
- Hero copy crossfades inside a fixed-height footprint.
- Website previews stay still and use native horizontal scrolling on phones.
- Hover and focus states use small color, glow, and position changes.
- The theme switch moves one compact control between sun and moon states.
- Pricing packages become a native swipe deck on mobile, with real neighboring cards peeking behind the active card.

All automatic motion pauses through visible controls. Reduced-motion users receive static content and manual slide selection.

## Conversion

The primary offer is a free custom website demo. The promise must remain explicit: Anthony builds a custom first direction; if the prospect does not move forward, it costs nothing. Supporting offers include transparent starting prices, a static launch option, two months of website care free for select clients, and an optional CMS at $100 per month.

## Accessibility and responsive behavior

Touch targets are at least 44px. Links have explicit destinations and visible focus. Mobile navigation is keyboard operable and scroll locking is limited to the open drawer. The hero supports horizontal swipes only when the horizontal gesture clearly exceeds vertical movement, and reserves space for its tallest mobile headline so slide changes never resize the section. The pricing deck supports native touch scrolling, arrows, dots, keyboard navigation, and reduced motion. The saved theme preference is respected; without a saved choice, dark mode is used. Logo marks keep their natural aspect ratios, and all text maintains strong contrast.
